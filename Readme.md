
Cases and its uses:
	Llanylib uses a mix mode of cases:
		snake_case:
            Primitive types (default)
            variables, signals names
            New types and subtypes (custom types)

		PascalCase:
            Entities
            Architectures (+ Arch at the end)
            Packages names

		camelCase:
			Package funtions

		FULL_MAYUS_WITH_UNDERSCORE:
            Constants
